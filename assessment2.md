# Python Assessment
## 1. Basic Logic
Write a program to check whether a number is prime.
## 2. Conditional Logic
Write a program to find the largest of three numbers.
## 3. Loop (for/while)
Write a program to print Fibonacci series up to N numbers.
## 4. String Handling
Write a program to check if a string is a palindrome.
## 5. List
Write a program to remove duplicates from a list.
## 6. Tuple
Write a program to count occurrences of an element in a tuple.
## 7. Set
Write a program to find intersection of two sets.
## 8. Dictionary
Write a program to count frequency of each character in a string using dictionary.
## 9. List Comprehension
Write a program to create a list of squares from 1 to 20 using list comprehension.
## 10. Lambda Function
Write a lambda function to sort a list of tuples based on second element.
## 11. Exception Handling
Write a program to handle division by zero exception.
## 12. File Handling
Write a program to read a file and count number of lines.
## 13. OOP – Class & Object
Create a class `Employee` with attributes and display method.
## 14. OOP – Inheritance
Create a class `Manager` that inherits from `Employee`.
## 15. OOP – Polymorphism
Demonstrate method overriding with example.
## 16. OOP – Encapsulation
Create a class with private variable and getter/setter methods.
## 17. OOP – Abstraction
Create an abstract class `Shape` with method `area()`.
## 18. Regular Expressions
Write a program to validate email using regex.
## 19. Sorting
Sort a list of dictionaries based on a key.
## 20. Searching
Implement binary search algorithm.
## 21. Real-world Problem
Write a program to find top 3 highest salaries from a list.
