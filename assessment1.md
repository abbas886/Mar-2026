# SQL / Oracle Assessment – Queries Only
## 1. DDL
Create a table `project` with columns: project_id (PK), project_name, start_date, budget.
## 2. DML (INSERT)
Insert a record into `employee` table with appropriate values.
## 3. UPDATE
Update salary of employees by 10% in department 1.
## 4. DELETE
Delete employees who joined before 2020.
## 5. WHERE Clause
Select employees whose salary is greater than 70000.
## 6. GROUP BY
Find total salary for each department.
## 7. GROUP BY with HAVING
Find departments where total salary is greater than 200000.
## 8. SUBQUERY
Find employees whose salary is greater than the average salary.
## 9. JOIN
Retrieve employee names along with their department names.
## 10. UNION / INTERSECT
Get list of employee names from department 1 and department 2 using UNION.
## 11. PL/SQL BLOCK
Write a PL/SQL block to display employee name for a given emp_id.
## 12. PROCEDURE
Create a procedure to update salary based on emp_id.
## 13. FUNCTION
Create a function to calculate bonus (10% of salary).
## 14. TRIGGER
Create a trigger to prevent salary from being reduced.
## 15. CURSOR
Write a cursor to display all employee names and salaries.
## 16. SEQUENCE
Create a sequence to generate employee IDs starting from 1000.
## 17. VIEW
Create a view to show employee name and department name.
## 18. INDEX
Create an index on employee salary column.
